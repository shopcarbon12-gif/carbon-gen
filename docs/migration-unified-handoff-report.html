Two kinds of backup (read this once)

Think of two separate pipelines — they are not the same thing:

  • Pipeline A — “Cursor / chat / profile” (usually lives on C:\ while you use Windows Cursor)
    Scripts copy it to one place on D: D:\backup c\ (folders like AppData-Roaming-Cursor, UserProfile-dot-cursor) and also make zips under D:\backup c\archives\.
    This is not your git source code; it is settings, extensions, workspace storage, transcript-style data.
  • Pipeline B — “Project repos” (your real code under D:\Projects\...)
    Scripts copy the two main repos into D:\backup c\project-repos\ and zip them under D:\backup c\project-repos\archives\.
    Heavy folders like node_modules are usually skipped to save space — you run npm install again on Ubuntu.

Ubuntu mirror (one folder): Everything you want off Windows eventually lands as one tree on Linux, e.g. /home/eliorp1/backup-from-windows-c/, which should mirror the whole D:\backup c\ layout (archives + project-repos + any reports).

Make the model look raw, not robotic

Same brief, same model, same panel intent — but every generation feels like a different real frame, not a copy-paste. Pose 1, Pose 7 (panel 4) and Pose 8 are the worst offenders today.

1 · Why it looks robotic right now

Your pose library (lib/panelPoseLibraries.ts) is genuinely good — it already defines variation options per pose (1A/1B/1C, 7A/7B/7C, 8 A–E) and even a rule: "choose ONE variation… do not repeat on back-to-back products." The problem is purely mechanical:

  • Nothing enforces the variation. The prompt text sent to OpenAI/Gemini is byte-for-byte identical every generation. So the model picks the same default (usually option A) and renders the same stance every time.
  • The face is hard-locked. The identity-lock reference photos pin the exact same face, expression and head angle — correct for brand consistency, but with zero micro-variation it reads as a cloned mannequin across a catalog.
  • No anti-repeat memory. The "don't repeat back-to-back" rule lives in text the model ignores; the system never tracks what it used last.

Net: identical prompt + locked face + no rotation = the AI-robotic feel. The fix is to let the system (not the model's free choice) rotate a controlled set of micro-variations each generation, and to add tiny, on-brand human variation to the face.

2 · The approach — 5 levers

1

System-driven variation (not model's choice)

For each generation, the code picks a specific variation (e.g. Pose 1 → 1B) and injects its exact micro-pose text into the prompt. Guarantees rotation instead of hoping the model varies.

2

Bigger variation pools

Expand each pose from 3 options to ~8–12 weighted micro-variations (weight shift, arm gap, head angle, gaze direction, toe-out, camera height, hand detail). More pool = less repetition.

3

Face & expression micro-variation

Within the identity lock: vary gaze direction, a subtle expression beat (calm ↔ quiet confidence), and a 2–8° head tilt. Same person — different candid moment, so it stops looking frozen.

4

Reference-photo rotation

Rotate which of the model's reference shots is primary each time, so the face is rendered from a slightly different source angle — kills the "exact same face" clone effect while keeping it the same person.

5

Anti-repeat memory + variation strength

Track the last variation used per pose per model and never repeat back-to-back. One global "Variation strength" knob (Subtle → Natural → Editorial) controls how far it drifts.

Today

Prompt: POSE 1 base… (same text)
→ same stance, same arms, same gaze, same face, every product. 50 items = 50 clones.

Proposed

Prompt: POSE 1 · variation 1F: weight on left, arms 2", chin 4°, gaze camera-left (rotated)
→ same hero pose family, 50 items feel shot in one real session.

4 · Face / expression variation (same person, different moment)

The biggest "robotic" tell is the frozen identical face. Within the identity lock we add a tiny, rotated beat — never enough to change who it is, just enough to feel candid:

Gaze to camera · calm
Gaze camera-left
Head tilt 5–8°
Quiet confidence beat

Combined with reference-photo rotation (use a different one of the model's source shots as primary each time), the same model stops rendering as an identical clone.

5 · Face strategy — your call

Option A · Recommended

Keep your one locked model, add the micro-variation above (gaze/expression/tilt + reference rotation). Stays 100% on-brand; each shot feels like a real session, not a clone. Lowest risk.

Option B · Optional

Maintain a small pool of 2–4 brand models and rotate per product. More face variety across the catalog, still curated. Bigger change (manage multiple identities), more "raw" variety.

6 · Variation strength (one global knob)

Subtle (tight, catalog-safe)Natural (recommended)Editorial (more drift)

Controls how far stance/gaze/expression can drift from base. "Natural" = clearly the same shoot, never two identical frames. You set it once; per-pose it still respects all your HARD LOCKS (white seamless, garment readable, no covered logos, full-body scale, close-up item lock).

7 · What stays locked (so it's still on-brand)

  • Identity — same model (Option A) / curated pool (Option B). Facial geometry + skin tone never drift.
  • Pose family — Pose 1 stays the hero, Pose 7 stays back-detail, Pose 8 stays creative. Only the micro-pose rotates.
  • All HARD LOCKS — pure white seamless, studio lighting, full-body scale match, garment readability, close-up item-type lock, the panel mapping.
  • QA gate — the existing compliance check still runs; variation never violates it.

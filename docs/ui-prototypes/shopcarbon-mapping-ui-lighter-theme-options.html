Lighter Theme Suggestions

These are three slightly lighter directions for the ShopCarbon collection mapping UI. They keep the same overall product feel, structure, and dark-mode intent, but lift panels, borders, and content contrast so the interface feels less heavy.

Option 1
Soft Slate Lift
Closest to current, but less blue and a little warmer. Think cleaner slate panels instead of heavy midnight navy.
